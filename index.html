Makeup Studio

Original Look Daily Makeup Tips

  • Start with clean, moisturized skin + SPF.
  • Use light BB/CC cream or tinted moisturizer; spot-conceal only.
  • Soft brows: fill sparse areas with pencil/powder, brush up.
  • Neutral eyeshadow (beige/taupe) + thin brown liner.
  • One coat of mascara; curl lashes first.
  • Cream blush on cheeks for natural flush; blend upward.
  • Highlighter only on high points.
  • Lip tint or nude lipstick; dab with finger for soft finish.
  • Set with light translucent powder only on T-zone.
  • Keep it fresh: blot oil, reapply lip tint through the day.

Less is more — enhance, don't mask. Remove fully before bed.

Always remove makeup before sleep and use SPF daily.

Wellness & Self-Care

👗 Dress Code for Different Jobs / বিভিন্ন চাকরির ড্রেস কোড

  • Corporate / Office / কর্পোরেট / অফিস: Blazer, formal shirt / blouse, tailored pants or pencil skirt, closed shoes, minimal jewelry. / ব্লেজার, ফরমাল শার্ট / ব্লাউজ, টেইলার্ড প্যান্ট বা পেন্সিল স্কার্ট, বন্ধ জুতা, হালকা গহনা।
  • Teaching / শিক্ষকতা: Modest kurti / saree or formal top with pants, comfortable flats, light makeup. / মার্জিত কুর্তি / শাড়ি বা ফরমাল টপ + প্যান্ট, আরামদায়ক ফ্ল্যাট, হালকা মেকআপ।
  • Healthcare / স্বাস্থ্য: Scrubs / uniform, hair tied up, no dangling jewelry, closed-toe shoes. / স্ক্রাবস / ইউনিফর্ম, চুল বাঁধা, ঝোলা গহনা নয়, বন্ধ জুতা।
  • Retail / Sales / রিটেইল / সেলস: Smart casual, brand colors, name tag, neat grooming, comfortable shoes. / স্মার্ট ক্যাজুয়াল, ব্র্যান্ডের রং, নেম ট্যাগ, পরিপাটি সাজ, আরামদায়ক জুতা।
  • IT / Tech / আইটি: Casual (jeans, t-shirt / hoodie) but neat; sneakers allowed. / ক্যাজুয়াল (জিন্স, টি-শার্ট / হুডি) কিন্তু পরিপাটি; স্নিকার্স চলবে।
  • Creative / Media / ক্রিয়েটিভ / মিডিয়া: Expressive, trendy, statement pieces; smart-casual balance. / এক্সপ্রেসিভ, ট্রেন্ডি, স্টেটমেন্ট পিস; স্মার্ট-ক্যাজুয়াল ব্যালেন্স।
  • Field / Outdoor / মাঠ / বাইরের কাজ: Durable fabrics, sun protection, closed shoes, hat / cap. / টেকসই কাপড়, রোদ থেকে সুরক্ষা, বন্ধ জুতা, টুপি / ক্যাপ।
  • Remote / Home / বাসা থেকে কাজ: Comfortable yet camera-ready top. / আরামদায়ক কিন্তু ক্যামেরায় সুন্দর দেখায় এমন টপ।

😊 Mood Elevation Tips / মন ভালো করার টিপস

  • Start day with 5 min gratitude journaling. / দিন শুরু করো ৫ মিনিট কৃতজ্ঞতা লিখে।
  • Listen to upbeat music or a favorite podcast. / মন ভালো করা গান বা প্রিয় পডকাস্ট শোনো।
  • Get 10-15 min sunlight and fresh air. / ১০-১৫ মিনিট রোদ ও তাজা বাতাস নাও।
  • Connect with a friend or loved one. / বন্ধু বা প্রিয়জনের সাথে কথা বলো।
  • Do one small task to build momentum. / একটা ছোট কাজ করে শুরু করো।
  • Limit doom-scrolling; set phone breaks. / ফোনে অযথা স্ক্রল কমাও; বিরতি নাও।
  • Reward yourself with a small treat after tasks. / কাজ শেষে নিজেকে ছোট একটা ট্রিট দাও।
  • Practice deep breathing (4-7-8) when stressed. / চাপ লাগলে গভীর শ্বাসের ব্যায়াম করো (৪-৭-৮)।
  • Wear colors you love; dress up a little. / পছন্দের রং পরো; একটু সেজে নাও।
  • End day with a relaxing hobby (reading, art). / দিন শেষে রিলাক্সিং শখ (বই, আঁকা) দিয়ে শেষ করো।

🌸 Menstrual Pain & Migraine Relief / পিরিয়ড ব্যথা ও মাইগ্রেনে আরাম

  • Apply heat pad / hot water bottle on lower abdomen. / তলপেটে গরম পানির বোতল / হিট প্যাড দাও।
  • Gentle yoga: child's pose, cat-cow, reclined twist. / হালকা যোগা: চাইল্ড পোজ, ক্যাট-কাউ, রিক্লাইন্ড টুইস্ট।
  • Drink warm water, ginger / peppermint tea. / কুসুম গরম পানি, আদা / পুদিনা চা খাও।
  • Light exercise / walk releases endorphins. / হালকা ব্যায়াম / হাঁটা এন্ডোরফিন বাড়ায়।
  • Magnesium-rich foods (dark chocolate, nuts, spinach). / ম্যাগনেসিয়াম যুক্ত খাবার (ডার্ক চকলেট, বাদাম, পালং শাক)।
  • Over-the-counter pain relief as advised by doctor. / ডাক্তারের পরামর্শে ব্যথার ওষুধ।
  • Avoid excess caffeine / salty foods; stay hydrated. / বেশি ক্যাফেইন / লবণাক্ত খাবার এড়াও; পানি খাও।

Migraine / মাইগ্রেন:

  • Rest in a dark, quiet room; cold compress on forehead. / অন্ধকার, শান্ত ঘরে বিশ্রাম; কপালে ঠান্ডা কাপড়।
  • Hydrate; avoid triggers. / পানি খাও; ট্রিগার এড়াও।
  • Gentle neck / shoulder stretches. / হালকা ঘাড় / কাঁধের স্ট্রেচ।
  • Track triggers in a diary. / ডায়েরিতে ট্রিগার লিখে রাখো।

🌅 Daily Morning Self-Care / প্রতিদিন সকালের যত্ন

  • Wake at a consistent time; avoid snoozing. / একই সময়ে ওঠো; স্নুজ এড়িয়ে চলো।
  • Drink a glass of water first thing. / সবার আগে এক গ্লাস পানি খাও।
  • 5-10 min stretching or yoga. / ৫-১০ মিনিট স্ট্রেচিং বা যোগা।
  • Wash face; moisturize; apply SPF. / মুখ ধোও; ময়েশ্চারাইজ করো; SPF দাও।
  • Healthy breakfast (protein + fiber). / স্বাস্থ্যকর নাস্তা (প্রোটিন + ফাইবার)।
  • Set 3 priorities for the day. / দিনের ৩টি প্রায়োরিটি ঠিক করো।
  • 10 min mindfulness / meditation. / ১০ মিনিট মাইন্ডফুলনেস / মেডিটেশন।
  • Light exposure: open curtains / step outside. / আলো নাও: পর্দা খোলো / বাইরে যাও।
  • Skincare: cleanse, tone, moisturize, SPF. / স্কিনকেয়ার: ক্লিনজ, টোন, ময়েশ্চারাইজ, SPF।
  • Positive affirmation before starting work. / কাজ শুরুর আগে পজিটিভ কথা বলো।

🧘 Yoga Practice (Beginner Friendly) / যোগা (নতুনদের জন্য)

  • Mountain (Tadasana): posture & grounding. / দাঁড়ানোর ভঙ্গি ও ভারসাম্য।
  • Downward Dog: stretches whole body. / পুরো শরীর স্ট্রেচ হয়।
  • Child's Pose: relaxes back & hips. / পিঠ ও হিপ রিলাক্স হয়।
  • Cat-Cow: spine mobility. / মেরুদণ্ড নমনীয় হয়।
  • Warrior I & II: strength & balance. / শক্তি ও ভারসাম্য।
  • Tree Pose: focus & stability. / মনোযোগ ও স্থিতি।
  • Bridge Pose: strengthens glutes / back. / গ্লুটস / পিঠ শক্ত হয়।
  • Seated Forward Bend: calms mind. / মন শান্ত হয়।
  • Corpse (Savasana): final relaxation. / শেষে সম্পূর্ণ বিশ্রাম।

🌙 Bedtime Self-Care Routine / রাতের যত্ন

  • Set a consistent sleep time; aim 7-9 hours. / একই সময়ে ঘুমাও; ৭-৯ ঘণ্টা ঘুমের লক্ষ্য।
  • Dim lights & reduce screen use 1 hour before bed. / ঘুমের ১ ঘণ্টা আগে আলো কমাও ও স্ক্রিন কমাও।
  • Gentle stretching or 5-min meditation. / হালকা স্ট্রেচিং বা ৫ মিনিট মেডিটেশন।
  • Warm shower / bath to relax muscles. / কুসুম গরম গোসল মাংসপেশি রিলাক্স করে।
  • Skincare: cleanse, moisturize, lip balm. / স্কিনকেয়ার: ক্লিনজ, ময়েশ্চারাইজ, লিপ বাম।
  • Write down tomorrow's 3 priorities. / আগামীকালের ৩টি কাজ লিখে রাখো।
  • Keep bedroom cool, dark, quiet. / ঘর ঠান্ডা, অন্ধকার, শান্ত রাখো।
  • Avoid heavy meals, caffeine, alcohol late at night. / রাতে ভারী খাবার, ক্যাফেইন, অ্যালকোহল এড়াও।
  • Read a few pages or listen to calm music. / কয়েক পাতা বই পড়ো বা শান্ত গান শোনো।
  • Gratitude reflection: 3 good things. / কৃতজ্ঞতা: ৩টি ভালো জিনিস মনে করো।

🥗 Healthy Eating Behaviour / স্বাস্থ্যকর খাওয়ার অভ্যাস

  • Eat mindfully: slow down, chew well, no screens. / মন দিয়ে খাও: ধীরে খাও, ভালো করে চিবাও, স্ক্রিন নয়।
  • Half plate veggies / fruits, quarter protein, quarter whole grains. / অর্ধেক প্লেট শাকসবজি / ফল, এক চতুর্থাংশ প্রোটিন, এক চতুর্থাংশ হোল গ্রেইন।
  • Drink water before meals; stay hydrated all day. / খাবারের আগে পানি খাও; সারাদিন হাইড্রেটেড থাকো।
  • Include lean protein, healthy fats, fiber. / লিন প্রোটিন, হেলদি ফ্যাট, ফাইবার রাখো।
  • Limit sugar, ultra-processed foods, excess salt. / চিনি, প্রসেসড খাবার, বেশি লবণ কমাও।
  • Don't skip breakfast; keep regular meal times. / নাস্তা বাদ দিও না; নিয়মিত সময়ে খাও।
  • Portion control: use smaller plates; stop at 80% full. / পরিমাণ নিয়ন্ত্রণ: ছোট প্লেট ব্যবহার করো; ৮০% ভরলেই থামো।
  • Snack smart: fruits, yogurt, nuts instead of chips. / স্মার্ট স্ন্যাকস: চিপসের বদলে ফল, দই, বাদাম।
  • Plan meals ahead; keep healthy options ready. / আগে থেকে খাবার প্ল্যান করো; হেলদি অপশন রেডি রাখো।
  • Listen to hunger cues; avoid emotional eating. / ক্ষুধার সংকেত শোনো; মন খারাপে খাওয়া এড়াও।

🚶 Everyday 10-Minute Walk / প্রতিদিন ১০ মিনিট হাঁটা

  • Walk 10 min daily — morning, lunch, or evening. / প্রতিদিন ১০ মিনিট হাঁটো — সকাল, দুপুর বা সন্ধ্যা।
  • Improves mood, circulation, digestion, sleep quality. / মন, রক্ত চলাচল, হজম, ঘুম ভালো হয়।
  • Helps weight management & reduces stress. / ওজন নিয়ন্ত্রণে সাহায্য করে ও চাপ কমায়।
  • Walk briskly but comfortably; swing arms. / একটু জোরে কিন্তু আরাম করে হাঁটো; হাত নাড়াও।
  • Use stairs, park farther, walk while on calls. / সিঁড়ি ব্যবহার করো, দূরে গাড়ি রাখো, ফোনে কথা বলতে বলতে হাঁটো।
  • Track steps with phone; set small goals. / ফোনে স্টেপ গোনো; ছোট লক্ষ্য ঠিক করো।
  • Walk with a friend or listen to podcast / music. / বন্ধুর সাথে হাঁটো বা পডকাস্ট / গান শোনো।
  • Wear comfortable shoes; stay hydrated. / আরামদায়ক জুতা পরো; পানি খাও।
  • Even 10 min adds up: ~1,000-1,200 steps. / মাত্র ১০ মিনিটেও ~১,০০০-১,২০০ স্টেপ হয়।
  • Make it a habit: same time each day. / অভ্যাস করো: প্রতিদিন একই সময়ে।

🧴 Skin Care Routine / স্কিন কেয়ার রুটিন

☀️ Morning Routine / সকালের রুটিন

  • 1. Cleanser / ক্লিনজার: Gentle face wash with lukewarm water. / হালকা গরম পানি দিয়ে মাইল্ড ফেসওয়াশ।
  • 2. Toner / টোনার: Rose water or alcohol-free toner. / গোলাপ জল বা অ্যালকোহল ছাড়া টোনার।
  • 3. Serum / সিরাম: Vitamin C serum for glow. / উজ্জ্বলতার জন্য ভিটামিন C সিরাম।
  • 4. Moisturizer / ময়েশ্চারাইজার: Light moisturizer for day. / দিনের জন্য হালকা ময়েশ্চারাইজার।
  • 5. Sunscreen / সানস্ক্রিন: SPF 30+ must, even at home. / SPF 30+ অবশ্যই, বাসায় থাকলেও।
  • 6. Lip Care / ঠোঁটের যত্ন: Lip balm with SPF. / SPF যুক্ত লিপ বাম।

🌙 Night Routine / রাতের রুটিন

  • 1. Double Cleanse / ডাবল ক্লিনজ: First micellar water / oil, then face wash. / প্রথমে মিসেলার ওয়াটার / অয়েল, তারপর ফেসওয়াশ।
  • 2. Toner / টোনার: Hydrating toner. / হাইড্রেটিং টোনার।
  • 3. Serum / সিরাম: Hyaluronic acid or Niacinamide serum. / হায়ালুরনিক অ্যাসিড বা নিয়াসিনামাইড সিরাম।
  • 4. Eye Cream / আই ক্রিম: Gentle dab around eyes. / চোখের চারপাশে হালকা করে লাগাও।
  • 5. Night Cream / নাইট ক্রিম: Rich moisturizer / night cream. / ভারী ময়েশ্চারাইজার / নাইট ক্রিম।
  • 6. Lip Balm / লিপ বাম: Thick lip balm before sleep. / ঘুমের আগে ঘন লিপ বাম।

📅 Weekly Care / সাপ্তাহিক যত্ন

  • Exfoliate / এক্সফোলিয়েট: 1-2 times a week, gentle scrub. / সপ্তাহে ১-২ বার, হালকা স্ক্রাব।
  • Face Mask / ফেস মাস্ক: 1-2 times a week as per skin type. / সপ্তাহে ১-২ বার ত্বকের ধরন অনুযায়ী মাস্ক।
  • Steam / স্টিম: Once a week for deep cleansing. / সপ্তাহে ১ বার ডিপ ক্লিনজিং এর জন্য ভাপ।

💡 By Skin Type / ত্বকের ধরন অনুযায়ী

  • Oily / তৈলাক্ত: Gel cleanser, oil-free moisturizer, clay mask. / জেল ক্লিনজার, অয়েল-ফ্রি ময়েশ্চারাইজার, ক্লে মাস্ক।
  • Dry / শুষ্ক: Cream cleanser, thick moisturizer, honey mask. / ক্রিম ক্লিনজার, ঘন ময়েশ্চারাইজার, মধুর মাস্ক।
  • Combination / মিশ্র: Gel cleanser, light moisturizer, clay on T-zone only. / জেল ক্লিনজার, হালকা ময়েশ্চারাইজার, শুধু T-zone এ ক্লে।
  • Sensitive / সংবেদনশীল: Fragrance-free, aloe + cucumber, patch test first. / সুগন্ধি ছাড়া, অ্যালো + শসা, আগে প্যাচ টেস্ট।
  • Acne-prone / ব্রণ প্রবণ: Salicylic acid cleanser, don't squeeze pimples. / স্যালিসিলিক অ্যাসিড ক্লিনজার, ব্রণ টিপো না।

⚠️ Don't Do / করো না

  • Don't sleep with makeup. / মেকআপ নিয়ে ঘুমিও না।
  • Don't use too many new products at once. / একসাথে অনেক নতুন প্রোডাক্ট ব্যবহার করো না।
  • Don't skip sunscreen. / সানস্ক্রিন বাদ দিও না।
  • Don't rub face with towel, pat dry. / তোয়ালে দিয়ে ঘষো না, হালকা চাপ দিয়ে মোছো।

🤲 Islamic & Religious Behaviour / Values / ইসলামিক ও ধর্মীয় আচরণ / মূল্যবোধ

  • Prayer (Salah) / নামাজ: Pray 5 times daily on time. / প্রতিদিন ৫ ওয়াক্ত নামাজ সময়মতো পড়ো।
  • Charity (Zakat / Sadaqah) / দান: Give regularly to those in need. / নিয়মিত অভাবীদের দান করো।
  • Honesty & Trust / সততা ও আমানত: Speak truth; keep promises. / সত্য বলো; ওয়াদা রাখো।
  • Modesty / শালীনতা: Dress and behave modestly. / শালীনভাবে পোশাক পরো ও আচরণ করো।
  • Kindness / দয়া: Be gentle with family, neighbors, animals. / পরিবার, প্রতিবেশী, প্রাণীর প্রতি কোমল হও।
  • Patience (Sabr) / ধৈর্য: Stay calm in hardship. / কষ্টে শান্ত থাকো।
  • Gratitude (Shukr) / কৃতজ্ঞতা: Thank Allah for blessings. / আল্লাহর নেয়ামতের জন্য শুকরিয়া আদায় করো।
  • Forgiveness / ক্ষমা: Forgive others. / অন্যদের ক্ষমা করো।
  • Knowledge / জ্ঞান: Seek beneficial knowledge. / উপকারী জ্ঞান অর্জন করো।
  • Respect for all faiths / সবার ধর্মের প্রতি সম্মান: Honor others' beliefs. / অন্যের বিশ্বাসকে সম্মান করো।
  • General values / সাধারণ মূল্যবোধ: Love, compassion, service, humility, justice. / ভালোবাসা, সহানুভূতি, সেবা, বিনয়, ন্যায়।
